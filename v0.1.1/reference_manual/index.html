SparseElementaryDivisors.SparseElementaryDivisors — Module
SparseElementaryDivisors

Elementary divisors (Smith normal form invariants) of large sparse integer matrices, by exact sparse elimination (unit pivots with Markowitz-style ordering, parallel pivot search and fill-in) followed by Hecke's elementary_divisors on the remaining core.

References (details in the bibliography of the documentation): Markowitz (1957) for the pivot score; LaMacchia and Odlyzko (1991) for the structured elimination; Dumas, Saunders and Villard (2001) on the Smith normal form of large sparse integer matrices; Fieker, Hart, Hofmann and Johansson (2017) for Hecke, with FLINT.

Main entry point: sparse_elementary_divisors, with its settings ReductionConfig and its statistics ReductionStats. See also read_matrix_market, write_matrix_market and magma_elementary_divisors (comparison with Magma, requires a Magma installation).

Documentation: https://yvesguiraud.github.io/SparseElementaryDivisors.jl/stable/

Elementary divisors of the integer matrix A (the non-zero diagonal entries of its Smith normal form), in increasing order: a d::Vector{BigInt} such that each d[i] divides d[i+1].

A can be a SparseMatrixCSC (fast path), any other AbstractSparseMatrix or AbstractMatrix{<:Integer} (converted), a Hecke matrix (Hecke.SMat{ZZRingElem} or Hecke.ZZMatrix), or the matrix given row by row: rows[r] is the vector of (column, value) pairs of row r, with columns in 1:n and strictly increasing, for an m × n matrix (zero values are allowed and ignored; values of any integer type, entries beyond a machine word included). The input is checked before the computation: an ArgumentError names the first fault (column out of range, unsorted or repeated column, wrong number of rows); unsorted triplets go through sparse(I, J, V), which sorts them and sums duplicates. With a file name, the matrix is read in Matrix Market format (see read_matrix_market).

  • value_type: integer type(s) of the coefficients during the elimination, with checked arithmetic. :auto (default) tries the types of SparseElementaryDivisors.DEFAULT_VALUE_TYPES = (Int32, Int64, Int128, BigInt) in turn, starting with the first one that holds all the entries, and restarts the computation from the input with the next type after an overflow (each matrix independently: a failed attempt costs its time). A type (value_type = Int64) uses that type only; a sequence (value_type = (Int64, Int128)) tries its types in turn. Accepted types: signed integers of fixed width (Int8 to Int128, or wider ones such as Int256 of BitIntegers.jl) in strictly increasing width, and BigInt last. When the last type does not suffice, a CoefficientOverflowError is raised.
  • config: the settings of the reduction, a ReductionConfig (pivot search, parallelism, format of the core, memory); the same for all the attempts of the widening.
  • settings...: any field of ReductionConfig given directly as a keyword, which takes precedence over config. The most common: nworkers (number of parallel tasks, default Threads.nthreads(); start Julia with -t auto or -t N; the result does not depend on it) and core_format (:auto, :sparse or :dense, format of the core passed to Hecke). An unknown keyword raises an ArgumentError.
  • stats: a ReductionStats, reset then filled in place: type retained, failed attempts, counters, times and core.
  • verbose: print the attempts that overflowed, the type retained, and the size and format of the core.

Developer tools: trace, a SparseElementaryDivisors.ReductionTrace (trajectory fingerprint of the attempt retained), and probe, a function of no argument called after each Markowitz pivot.

Method: a structured elimination (LaMacchia and Odlyzko 1991) pivots on the rows and columns of degree one whose entry is ±1; then each step pivots on a ±1 entry of small Markowitz score (r − 1)(c − 1) (Markowitz 1957), r and c being the numbers of entries of its row and column, and the structured elimination runs again. Each ±1 pivot gives an elementary divisor 1; the core that remains, with no ±1 entry left, goes to Hecke.elementary_divisors (Fieker, Hart, Hofmann and Johansson 2017; FLINT). On the Smith normal form of large sparse integer matrices, in particular from homology, see Dumas, Saunders and Villard (2001). References in the bibliography of the documentation.

Settings and statistics

SparseElementaryDivisors.ReductionConfig — Type
ReductionConfig(; kwargs...)

Settings of one attempt of the reduction, each with its default; an immutable value, which can be kept and reused (for instance for all the differentials of a complex). Pass it to sparse_elementary_divisors with the keyword config; each field can also be given there directly as a keyword, which then takes precedence over config:

cfg = ReductionConfig(nworkers = 4, core_format = :sparse)
sparse_elementary_divisors(A; config = cfg)
sparse_elementary_divisors(A; config = cfg, nworkers = 1)     # nworkers = 1 wins
sparse_elementary_divisors(A; search_mode = :never)           # without building a config

No setting changes the elementary divisors; the pivot search parameters change the order of the pivots (hence the time, the fill-in and the size of the coefficients), the others only how the work is done. The values are checked at construction (ArgumentError).

Pivot search (±1 pivots, Markowitz score (row degree - 1)(column degree - 1) after Markowitz (1957), columns visited by increasing degree):

  • acceptable_score_threshold = 4: the search stops at the first pivot whose score is at most this value (≥ 0);
  • max_buckets_scanned = 1: maximum number of non-empty degree buckets visited by a search (≥ 1).

Parallelism (the result does not depend on it, bit for bit):

  • nworkers = nothing: number of workers, the calling thread included; nothing means Threads.nthreads() at the time of the call (start Julia with -t auto or -t N);
  • apply_min_work = 25_000: work (entries traversed by the merges of a pivot) below which the application of a pivot stays sequential;
  • apply_chunk_max = 32: maximum size of an application chunk;
  • search_mode = :auto: :auto (cost rule below), :always (parallel as soon as nworkers > 1), :never, or :floor (parallel when the bucket has at least search_parallel_min_work entries, without the cost rule);
  • search_parallel_min_work = 5000: floor of the :auto rule, in bucket entries;
  • search_ns_per_entry = 8.0, parallel_fixed_cost_ns = 50_000.0, apply_parallel_penalty = 0.1: constants of the :auto rule, calibrated on a 24-thread workstation (Intel Core Ultra 9 285): a bucket of e entries is scanned in parallel when the saving e · search_ns_per_entry · (1 - 1/nworkers) exceeds parallel_fixed_cost_ns + apply_parallel_penalty · (recent application time in ns);
  • apply_ema_alpha = 0.05: weight of the moving average of the application time, in (0, 1];
  • search_chunk_min = 4, search_chunk_max = 256: bounds on the size of the search chunks (columns).

Core (what the elimination leaves, passed to Hecke):

  • core_format = :auto: :sparse (SMat), :dense (Flint ZZMatrix, an extraction without pressure on the garbage collector: ZT2w4m5 d₄, 0.6 s instead of 422 s), or :auto (dense when the density of the core is at least dense_min_density and its dense form takes at most dense_max_bytes bytes, sparse otherwise);
  • dense_min_density = 0.05, in [0, 1];
  • dense_max_bytes = 16 * 2^30.

Memory:

  • release_empty_vectors = false: if true, a row or column that becomes empty during a merge gets fresh vectors, which frees its capacity (by default its vectors are emptied and keep their capacity). On Windows, this reduced the heap of ZT2w4m5 d₄ from 22 to 9 GiB, but about doubled the total time (garbage collection); not measured on Linux yet.

SparseElementaryDivisors.ReductionStats — Type
ReductionStats()

Statistics of a computation, filled in place by sparse_elementary_divisors through its keyword stats:

st = ReductionStats()
d = sparse_elementary_divisors(A; stats = st)
st.value_type        # the integer type retained by the widening

All the fields are reset at the start of each call. The counters, times and core describe the attempt retained (the one that did not overflow); with value_type = :auto or a sequence of types, the attempts that overflowed before it are listed in failed_attempts. One object per computation: two computations running at the same time must not share it.

Widening:

  • value_type: the type retained, nothing before the end of a computation (and after an error);
  • failed_attempts: the attempts that overflowed, as (value_type, unit_pivots, seconds), in order; the last one included when the last type does not suffice (the error is then raised).

Elimination (attempt retained):

  • unit_pivots: ±1 pivots of the structured elimination and of the Markowitz loop, that is the elementary divisors equal to 1 found before the core;
  • markowitz_pivots: those of the Markowitz loop;
  • parallel_searches, sequential_searches: bucket scans of the pivot search, parallel or sequential;
  • parallel_applications, sequential_applications: pivot applications (merges), parallel or sequential.

Times, in seconds:

  • sge_seconds, search_seconds, apply_seconds: structured elimination, pivot search, pivot application;
  • core_seconds: extraction of the core and its elementary divisors by Hecke.

Core and context:

  • core_size: (rows, cols, nnz) of the core left by the elimination;
  • core_format: :none (empty core), :sparse or :dense (see core_format in ReductionConfig);
  • nworkers: number of workers used.

Integer types and overflow

SparseElementaryDivisors.DEFAULT_VALUE_TYPES — Constant
SparseElementaryDivisors.DEFAULT_VALUE_TYPES

The sequence of integer types tried by value_type = :auto, in increasing width: (Int32, Int64, Int128, BigInt). Int32 comes first because it saves time and memory on large matrices (on the differentials of the dual braid monoid of G₃₇, in trivial coefficients, it saves 20% of the time and 17% of the peak memory compared with Int64), and its failed attempts cost little when the coefficients grow (their overflow comes early).

SparseElementaryDivisors.CoefficientOverflowError — Type
CoefficientOverflowError(value_type, unit_pivots, entry)

The integer coefficients do not fit in value_type. Raised by sparse_elementary_divisors when the last type of the sequence given by its keyword value_type does not suffice; with the default value_type = :auto, whose sequence ends with BigInt, it is never raised.

  • value_type: the type that overflowed;
  • unit_pivots: number of unit pivots done before the overflow (0 for an input entry);
  • entry: nothing for an overflow during the elimination, or (row, column, value) of an input entry that does not fit in value_type.

Matrix Market files

SparseElementaryDivisors.read_matrix_market — Function
read_matrix_market(path_or_io) -> SparseMatrixCSC{Int,Int}

Read a matrix in Matrix Market format (Boisvert, Pozo and Remington 1996, references in the bibliography of the documentation): coordinate (the format suited to sparse matrices) or array, of type integer or pattern (all entries equal to 1); real is accepted if all values are integers. The symmetry can be general, symmetric or skew-symmetric (the latter two for coordinate only). Comment lines (%) are ignored. The values are read as Int: an entry beyond a machine word raises an error. See also write_matrix_market.

SparseElementaryDivisors.write_matrix_market — Function
write_matrix_market(

    )

write_matrix_market(
    io::IO,
    A::AbstractMatrix{<:Integer};
    comment::Union{Nothing,AbstractString,Vector{<:AbstractString}} = nothing
    )

Write the integer matrix A (a SparseMatrixCSC{<:Integer}, or any AbstractMatrix{<:Integer}, converted by sparse) in Matrix Market format (Boisvert, Pozo and Remington 1996), coordinate integer general: the header line, the comment lines, the line m n nnz, then one line i j v per nonzero entry, sorted by row, then by column. The stored zeros are left out (nnz counts the entries written); the values are written in decimal, whatever their integer type (BigInt included); the lines end with \n on every system. The same matrix written with the same comment always gives the same bytes.

comment: nothing, a string (several lines if it contains \n) or a vector of strings; each line is written after %. An existing file is overwritten. Returns nothing.

read_matrix_market reads such a file back, with values of type Int: an entry beyond a machine word can be written but not read back yet.

write_matrix_market("d2.mtx", A; comment = "d_2 of B*(G34), trivial coefficients")

Compute the elementary divisors of A with Magma (Bosma, Cannon and Playoust 1997, references in the bibliography of the documentation), to compare results and timings. Return (divisors::Vector{BigInt}, t_magma::Float64), where t_magma is the time measured by Magma itself for the single call to ElementaryDivisors (excluding the connection, the start-up of Magma and the transfer of the matrix; NaN if it could not be read). A can be of any type accepted by sparse_elementary_divisors, including a Matrix Market file name.

Without ssh_host, magma_command is run locally; otherwise the command is run through ssh -o ConnectTimeout=… ssh_host magma_command. The matrix is sent on the standard input.

See magma_elementary_divisors for a version returning only the divisors.

Developer tools

Public names that are not exported: they are reached as SparseElementaryDivisors.ReductionTrace and SparseElementaryDivisors.RowsData.

SparseElementaryDivisors.ReductionTrace — Type
SparseElementaryDivisors.ReductionTrace()

Trajectory fingerprint, a developer tool (public, not exported): passed to sparse_elementary_divisors with the keyword trace, it receives a running hash (FNV-1a on 64-bit words) of the Markowitz pivots (row, column) and of the calls of the structured elimination, in order. Two computations with the same fingerprint chose the same pivots in the same order; the test suite compares it with references computed by v0.1.0, for 1 to 4 workers and with the parallel paths forced. Reset at the start of each attempt of the widening: it describes the attempt retained.

Fields: h (hash), n_pivots (Markowitz pivots), n_sge (calls of the structured elimination), sum_ones (unit pivots found by the structured elimination).
